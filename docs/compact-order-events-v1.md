# Compact order journal transport v1

The `order_events_compact_v1` capability advertises `mode=READ_ONLY`, `default_wire_mode=full` and `supported_wire_modes=[full, shadow, compact]`. Full reads use the existing v1 journal. Shadow reads compare the v1 and compact pages within a signed frozen cut. A consumer can explicitly select compact as its primary journal transport (`compact_primary_opt_in=true`). It verifies the immutable references and reconstructs the public v1 events before ingestion. `grants_trading_authority=false` applies to every read mode. Formal recovery continues to use its v1 evidence route. The compact format is `ORDER_EVENT_DELTA_V1` and requires the persistent evidence stream.

For dual reads request the first v1 page with `pair_compact=true`. The response includes `compact_start_cursor`, a server-signed compact-route cursor starting at the same requested after and binding the v1 stream, account, executor, watermark, immutable tail anchor, receipt mode and expiry. Read the first compact page with that cursor, then use each route's own next_cursor. Concurrent appends belong to a later cut. An unavailable paired cursor fails the shadow read. Plain v1 and direct compact requests do not request a paired cursor.

GET `/order_events_compact_v1?after=0&limit=100` accepts the v1 paging parameters and enforces its fixed watermark, continuity, retention, and route-bound cursor checks. Every source event appears once at its original sequence, including events without economic changes. Every entry contains its event_id, type, recorded_at, source_ref, base_ref and ordered changes. A reference binds stream_id, account_id, account_type, event_id, order_id, order_version and sha256. The digest is SHA-256 over the public v1 row (event_id, type, recorded_at, data) serialized by Python json.dumps with sorted keys, UTF-8, ensure_ascii=False, allow_nan=False and separators=(',', ':'). The digest checks identity and integrity under the same deployment trust as v1.

Start with the base reference's verified public v1 data or an empty object for a null base. Apply changes in order. Path components are exact object keys or integer array offsets. `set` assigns value at the path, `remove` deletes the key, and `splice` replaces delete entries at start with items in the referenced array. The result restores the complete v1 public order, including changed and removed risks, historical broker raw fields, fill corrections and known or unknown fees. Verify the reconstructed row against source_ref. A complete base is sent when no same-order row is available at the page boundary or in this page. Account event IDs can interleave orders and order versions can skip.

GET `/order_event_source_v1` takes all seven reference fields as query parameters. It returns source_ref and the corresponding full public v1 event from the immutable journal. Unknown, missing, mismatched or altered sources fail closed. Consumers must not substitute the current order, a newer fill or an empty event. Formal recovery reads v1 independently. A whole-database clone has v1's existing lineage limitation.

Transport and retention are separate from the [optional schema 6 storage mode](order-journal-storage-v6.md). Both full storage and schema 6 reconstruct the public v1 document before projecting compact changes. Initial baselines and frequent switches between orders can cost more than v1. Check paired deltas and business projections in shadow mode before selecting compact as the primary read transport.

With explicit `include_void_receipts=true`, mixed coverage can also contain a standalone NON_FINANCIAL_SEQUENCE_VOID event. Its compact row contains event_id, type, recorded_at, source_ref, base_ref=null, and receipt (the complete attested receipt). The reference uses kind=NON_FINANCIAL_SEQUENCE_VOID in place of order_id and order_version. Both the full public row digest and the receipt's internal digest must match. The lookup route accepts these five scope/identity/digest fields plus kind. Original-only access does not expose these rows. A void row cannot serve as an order's delta base.
